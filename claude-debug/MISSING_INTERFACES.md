# Summary

Yapocis3 knows 47 interfaces:

- **21 packaged** in Yapocis3 itself. All 21 are in yapocis-rs's bundle and have CPU ports.
- **26 project interfaces** from `YAPOCIS_PROJECT=/Users/seant/workspace/yapocis_external`. None is in yapocis-rs's bundle, so none has a CPU port.

25 of the 26 are vendored in impressionist-rs's second bundle (`crates/yapocis-external`), so Rust can run them on GPU backends. `mandelbrot2` is the exception: it is in no Rust bundle.

Every one has OpenCL, Metal, CUDA and numbax templates in yapocis_external. Together the OpenCL templates come to about 2,500 lines.

# Notes

- **Templates with no interface:** yapocis_external's `kernels/ocl/` also has `hanbury.mako`, `hmedian.mako`, `inker.mako` and `rougier.c`. No interface file declares them, so they are not interfaces.
- **Where CPU ports would go:** `yapocis-rt`'s CPU backend chooses ports by interface name, and these are not yapocis-rs's interfaces. A CPU port for them would belong with impressionist-rs's `yapocis-external` crate, which needs a way to register its kernels with yapocis-rt.
- **`gaussian` is a project interface,** not Yapocis3's. Yapocis3's Gaussian library uses `convolvesep`.
